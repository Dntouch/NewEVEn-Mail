# Gestaltung und Herkunft

- `design-reference.png`: vom Benutzer bereitgestellte Gestaltungsvorlage.
- `earth-source.png`: für dieses Projekt mit der Imagegen-Skill generierter
  Hintergrund; enthält keine Formulare, Texte oder Logos. Im Build zu WebP
  komprimiert (etwa 196 KB beim ersten geprüften Stand).
- `overlays/public/branding/neweven/mark.svg`: eigene skalierbare Umsetzung der
  Pinguin-/Briefumschlag-Richtung. App-Icons werden daraus erzeugt.

Die Login-Seite ist eine echte React-Oberfläche mit Bulwark-Eingabefeldern,
kein als Website angezeigter Screenshot. Systemschriften vermeiden externe
Font-Abhängigkeiten. Die Bildmarke ist ein erster Entwurf zur weiteren Abstimmung.
